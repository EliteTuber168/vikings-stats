Sign in

This page saves changes straight to your GitHub repo, so it needs a GitHub access token. You only do this once per device.
  1. Open GitHub → New fine-grained token.
  2. Name it anything. Set Expiration to whatever you like.
  3. Repository access → Only select repositories → vikings-stats.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token, paste it below.
The token is stored only in this browser. Never share it — anyone with it can edit your stats.
